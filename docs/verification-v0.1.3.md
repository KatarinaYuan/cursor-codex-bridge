# v0.1.3 验证范围

此版本修复共享 tmux 会话在窄终端中发送长消息时，Cursor 的六行输入视口隐藏首行、导致完整草稿校验失败的问题。

自动化回归覆盖：软换行消息的自动扩宽与全文验证、失败草稿重试且不再次粘贴、已有草稿及审批覆盖层拒绝、隐藏首行被修改、重绘延迟、原进程更换、窗口尺寸与选项继承恢复、并发布局修改保护，以及提交后清理失败不误报为发送失败。

本版实际运行结果：339 项 Node 测试、31 项远端安装器测试通过，无跳过。

另完成一套实际部署下的端到端验收：原会话长时间闲置后，用户在 App 中断开并重新连接 SSH，再向窄终端中的原会话发送长消息，收到精确校验回复。最终复测中，Cursor 来源和原生聊天记录各新增一轮成功收发；原会话、进程和模型保持，窗口自动扩宽后恢复原尺寸及选项继承关系。

首次实测在扩宽后的残缺重绘帧上提前拒绝，发生在粘贴前，Cursor 来源未新增消息。本版补齐了有界的完整重绘等待，并在重新部署、App 重连后通过上述复测。观测器仅读取窗口尺寸与画面，没有手动调整窗口。

扩宽只用于独占且未缩放的 tmux 窗口，列宽上限为 1007；不会结束或重启原 Cursor Agent。无法仅用列宽解决的超过六个显式行的短消息会在粘贴前拒绝。超过 800 个 UTF-16 字符的粘贴继续走 Cursor 折叠标记及原文核验。

自动化使用虚构数据；真实账户、机器、SSH 别名、聊天、数据库、窗口画面及会话标识均不随仓库或安装包发布。此处仅记录脱敏后的验收范围；一次部署验收不能替代其他环境的 App 端到端验收。
