# 隐私与问题反馈

桥运行在你的 SSH 用户权限下，能读取该用户的 Cursor 会话，并向已绑定的 Agent 提交你从 Codex 发出的文字。Cursor 原有权限设置继续生效；桥不会自动开启 `--force`、`--trust` 或修改永久 allowlist。

桥不分发 Cursor、Codex 或 SSH 登录凭据。安装时使用你的既有 SSH 配置和远端登录状态。不要向维护者提供 token、私钥、密码或账号访问权限。

公开测试仅使用合成会话标识、示例用户路径和文档保留地址；不要把真实会话、主机配置或终端记录复制成测试数据。

## 本地保存什么

远端桥记录包含聊天正文、工作目录、模型和 Cursor/原生会话 ID；私有 socket 和映射记录使用用户私有权限。日志默认不记录聊天正文，但会包含方法名、参数键、生命周期以及部分会话和模型标识。路径、主机别名和版本组合也可能具有识别性。

`doctor` 不启动付费推理，也不向现有会话发送测试消息。其输出用于定位安装和连接问题，不承诺自动删除所有个人信息；分享前先检查。

卸载保留桥记录与原 Cursor 数据。需要删除保留数据时，以本次安装输出的位置为准，先备份再清理；不要按网络示例递归删除整个 `.cursor` 或 `.codex`。

## 反馈方式

普通兼容问题可在 GitHub issue 中提供复现步骤、版本和脱敏诊断。怀疑涉及凭据泄露或跨用户访问的问题时，不要把真实数据公开到 issue；使用仓库提供的私密安全报告入口。若该入口不可用，先提交不包含利用细节和个人数据的问题，要求维护者提供私密联系渠道。

新版本的 Cursor 终端界面或 Codex 协议可能让桥停止识别输入。此时拒绝发送是预期保护行为。项目是实验性兼容实现，安装成功不能替代对具体工作流的验收。
