# v0.1.13 验证范围

本版处理完整来源已完成、但重复用户封套使旧外部观察一直显示运行中的特定情况。自动收尾仅允许结构可证明的 `v1` 外部观察：此前稳定的封套后来出现重复，完整来源已完成，原先同一存活 Cursor 进程绑定仍成立，并且新捕获的画面确认输入可用、任务不忙碌。私人草稿可以保留，不会被清空。

失去来源归属的旧观察预览保留为已中断，并附明确说明；正式完成的来源卡片完整导入，不把歧义来源声明为实时归属。检查会周期重试，在重启后和来源内容未变化时同样执行。收尾只改变桥的显示记录，不向 Cursor 输入，不重发请求，不改变原进程、会话、模型或草稿。

原生 `v2` 已提交请求仍需自己的稳定来源与恢复凭据；来源 ID 歧义时继续保留等待，不能重绑、重发或假报完成。缺失外部观察结构、来源尚未完成、原进程不匹配或画面仍忙碌时也不自动收尾。回归需覆盖这些拒绝条件，以及重启、未变化来源的周期重试和收尾后不再出现歧义实时观察。
