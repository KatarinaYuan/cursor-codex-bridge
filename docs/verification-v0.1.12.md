# v0.1.12 验证范围

本版处理多行草稿只读扫描中的一种延迟渲染：光标已经移动，斜杠菜单相关画面仍停留在前一扫描位置，严格核验因此拒绝继续。修复仅允许在画面精确匹配已知前一视口时，有界追加画面捕获，等待当前预期位置精确呈现。

等待期间不增加方向键，不编辑正文，不按 Escape，也不发送 Enter。前一视口只允许触发等待，不能当作当前位置核验成功；光标没有偏差容限。若出现其他视口变化、无法精确匹配或超过等待边界，仍保留草稿并拒绝提交。原文、空行、首尾换行、原进程与模型、来源恢复凭据、末尾完整模型状态栏和标记移除前的核验继续适用。

验证应覆盖前一视口短暂残留后精确恢复的正例，并确认额外操作只有画面捕获。拒绝条件应包括未经确认的光标偏差、不同的正文或视口、未知菜单、等待超时及末尾状态栏未恢复。完整发送还应确认没有重复粘贴或方向键、标记移除后只有一次提交，并保留原文换行、收到回复且回到空闲状态。

v0.1.11 的附件重传恢复范围保持不变：必须已有严格失败草稿凭据，仅官方单附件包装的 UUID 路径可变化，其余全文及两份非符号链接普通文件的内容必须逐字节一致。原生队列保留原请求摘要；本版不会自动提交历史业务消息。详见 [v0.1.11 验证说明](verification-v0.1.11.md)。

分发版本与安装 skill 固定到 v0.1.12。安装器新增未修改的官方 v0.1.11 skill 两文件摘要识别，匹配后先备份再原子更新；此前官方版本以及自定义内容、额外文件和符号链接的保护保持不变。

打包时状态：候选代码已通过多行发送回归和独立审查；实际部署及用户授权消息与附件的往返验收将在该包上继续执行。版本、安装或分发测试通过不能替代真实原文换行、回复和空闲状态的验收；实际结果记录在 [v0.1.12 发布说明](https://github.com/KatarinaYuan/cursor-codex-bridge/releases/tag/v0.1.12)。斜杠菜单扫描边界见 [v0.1.10 验证说明](verification-v0.1.10.md)。
