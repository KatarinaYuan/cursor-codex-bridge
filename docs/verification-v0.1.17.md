# v0.1.17 验证范围

本版修复空闲输入框的一种状态栏误判：较长工作目录之后的完整 ` · ` 分隔符刚好结束于输入框右边缘，分支名单独换到下一行时，旧版报 `unrecognized-footer-or-overlay`，虽然 Cursor 历史仍可正常同步。

## 识别边界

新增布局必须同时满足：前一行精确填满完整输入框列宽、最后三字符为 ` · ` 或 ` • `、其余字符为 ASCII，下一行与路径行同缩进、只含一个分支名且为最后一行。所有可见状态栏字符必须保持受支持的灰色样式。原模型状态栏、完整输入框、空输入样式和提交前后校验保持原要求。

此变化不关闭菜单、不调整用户窗口、不清除草稿、不改变模型，也不自动重发失败的业务消息。审批文字、未知附加行、错误宽度或缩进、Unicode 路径换行和粘贴后正文变化仍会阻止发送。

## 已执行的回归

- 新增正常布局测试在修复前复现拒绝，修复后通过；保留的真实终端快照也由误拒绝转为可发送的空闲状态。
- 两种分隔符、原有其他换行位置、已有草稿、宽度偏差、空格填充、样式变化、审批词、额外菜单和输入变动均有回归覆盖。
- 发送路径核对一次粘贴、一次 Enter、来源完成收尾；已有草稿和粘贴后正文变化不发送 Enter。
- 全量 Node 测试 709 项：693 项通过、0 项失败、16 项平台或环境限定测试跳过。Python 安装器 31 项通过。独立审查的 screen/live 定向测试 198 项通过。
